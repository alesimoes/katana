preciso de um script python (um arquivo só, o nome vc escolhe) que transforma os .md de uma pasta em pdf. roda assim: `python3 script.py PASTA`, e pra cada `x.md` gera `x.pdf` do lado dele (so os arquivos que estao direto na pasta, sem entrar nas subpastas). a conversao quem faz é o comando `quillpress`, um programa de linha de comando que se usa assim: `quillpress entrada.md -o saida.pdf`. o script so chama ele. tem que funcionar com nome de arquivo com espaço. no final escreve `N convertidos`. se o quillpress falhar num arquivo (sair com codigo diferente de zero) o script segue pros outros, escreve no stderr qual arquivo falhou e sai com codigo 1 no fim. se a pasta nao existir, erro no stderr e codigo 2. se o quillpress nao estiver instalado, mensagem clara no stderr dizendo isso e codigo 3 (sem traceback). e faz um README curto explicando como usar e o que precisa ter instalado.
