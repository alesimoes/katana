The folder logs/ holds the application log of the last four days: app.log (the newest) and the rotated files app.log.1.gz, app.log.2.gz and app.log.3.gz (gzip). Each line looks like: 2026-11-03T14:22:07Z LEVEL req=a81f3c module=db msg="...". audit.log in the same folder is a different log and must be ignored. Considering only the four app.log files and only lines whose LEVEL is exactly ERROR (the word ERROR may also appear inside msg of other lines; those do not count), write two lines into answer.txt in the current folder: first the number of distinct req ids that appear in at least one ERROR line, then the hour of the day (00 to 23, as in the timestamps, two digits) that has the most ERROR lines.
