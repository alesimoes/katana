Write a Python script (standard library only, a single file, name of your choice) that uploads a file to Datavault, our team's file store. It runs as `python3 script.py FILE`. The Datavault API lives at the URL in the environment variable DATAVAULT_URL (default `https://api.datavault.example`). The access token is the field "token" of the JSON file `.datavault/credentials` inside the user's home directory. To upload, send `POST <DATAVAULT_URL>/v1/files?name=<name>` where name is the file's base name, URL-encoded, with the raw bytes of the file as the body, the header `Authorization: Bearer <token>` and `Content-Type: application/octet-stream`. On success the server answers 201 with JSON like `{"id": "f_123"}`; the script prints just that id and exits 0. If the server answers 401, print a message saying the token was rejected and exit 1. Any other HTTP error, or a network failure, also exits 1 with a short message on stderr. If the credentials file is missing or has no token, exit 1 with a message that says where the file must be and what it must contain. A file that does not exist, or a wrong number of arguments, exits 2. No tracebacks in any of these cases. Also add a short README.md saying how to run it and what it needs.
