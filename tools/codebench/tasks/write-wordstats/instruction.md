Create a Python package called `wordstats` in the current folder (standard library only) that counts words in text. It has three modules that import each other. `wordstats/tokenizer.py`: `tokenize(text)` returns the list of lowercase words in order of appearance. A word is a run of letters or digits (accented letters such as "á" or "ç" count as letters), and it may contain single apostrophes or hyphens between letters or digits, so "Don't" gives "don't" and "state-of-the-art" stays one word; any other character, including an apostrophe or hyphen at the start or end of a word and underscores, separates words. `wordstats/counter.py`, built on the tokenizer: `count(text)` returns a dict from word to number of occurrences, and `top(text, n=3)` returns the n most frequent words as a list of `(word, count)` tuples, most frequent first, ties broken alphabetically. `wordstats/report.py`, built on the counter: `render(text, n=3)` returns a string with one line `word: count` per top word (no trailing newline), or `(no words)` when the text has none. The package itself must export `tokenize`, `count`, `top` and `render`, and `python3 -m wordstats FILE [-n N]` must read the UTF-8 file, print the report, and exit with code 1 and a message on stderr when the file does not exist (a non-integer N is a usage error, exit code 2).
