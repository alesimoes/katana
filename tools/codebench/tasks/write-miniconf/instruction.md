Write a Python module `miniconf.py` (standard library only, in the current folder) that reads and writes a small configuration format.

The format: a line `[name]` alone starts a section (names use letters, digits, `_`, `.` and `-`); every other non-blank line is an entry `key = value` (same characters for keys, spaces around `=` optional). Entries before the first section are top-level entries. `#` starts a comment that runs to the end of the line, unless it is inside a double-quoted string; blank lines and comment-only lines are ignored.

Values: `-12` is an int, `3.5` or `-0.25` is a float, `true` and `false` are bools, a double-quoted string supports the escapes `\"`, `\\`, `\n` and `\t` and may contain spaces and `#`, a list is written `[1, "a b", true]` with scalar items only (`[]` is the empty list), and anything else is a bare string, taken as is with surrounding spaces trimmed (`host = example.org`).

`parse(text)` returns a dict: top-level entries are plain keys and each section is a nested dict stored under its name, in file order. Problems raise `ParseError` (a subclass of `ValueError`) whose message starts with `line N:` (N counts from 1): an entry without `=`, a bad key or section name, an unterminated string, text after a closing quote, an unterminated list, a nested list, a duplicate key in the same place, a duplicate section, an empty value.

`dumps(data)` is the inverse, and `parse(dumps(d)) == d` must hold for any valid dict. Output rules, exactly: top-level entries first, then each section preceded by one blank line and a line `[name]`; entries are `key = value` one per line; strings are always double-quoted (escaping `\`, `"`, newline and tab); bools are `true`/`false`; floats and ints use Python's `repr`; lists look like `[1, "a", true]`; the text ends with a newline, and an empty dict gives the empty string. `dumps` raises `ValueError` for anything the format cannot hold (a dict nested deeper than one section, a key or section name with invalid characters, a list inside a list, values of other types, floats that Python writes in exponent form such as 1e+20, nan and inf).
