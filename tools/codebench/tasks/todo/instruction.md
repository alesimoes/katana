todo.py has stubs for a tiny persistent to-do list stored as JSON in a file. Implement: add(path, text) -> int (new id, ids start at 1 and never repeat, even after items are removed), list_items(path, only_open=False) -> list of dicts {"id": int, "text": str, "done": bool} in id order, done(path, item_id) marks an item as done (KeyError if the id does not exist), remove(path, item_id) deletes it (KeyError if missing). A missing or empty file means an empty list. Empty or whitespace-only text raises ValueError. The file must stay valid JSON after every call.
