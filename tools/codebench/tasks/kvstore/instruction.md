Build a small persistent key-value store in the package kv/ (kv/__init__.py already exists and is empty). First create kv/store.py with a class Store(path). The data lives in the text file `path` as an append-only log with one JSON object per line: {"op": "set", "key": k, "value": v} or {"op": "del", "key": k}. Opening a Store replays the log; a missing file is an empty store. Methods: set(key, value) stores any JSON value and appends one line; get(key, default=None); delete(key) returns True and appends a del line when the key existed, and returns False and writes nothing otherwise; keys() returns a sorted list; len(store) is the number of live keys; compact() rewrites the file with exactly one set line per live key, in sorted key order, and returns how many lines were removed. A key must be a non-empty string, otherwise set, get and delete raise ValueError. Every change must be on disk when the method returns, so a second Store opened on the same path sees it. Then create kv/cli.py with a function main(argv) that returns an exit code and prints to standard output; argv is [path, command, ...]: "set KEY JSON" prints OK; "get KEY" prints the value as JSON, or prints NOT FOUND and returns 1; "del KEY" prints DELETED, or prints NOT FOUND and returns 1; "keys" prints one key per line; "compact" prints "removed N". A value that is not valid JSON, an unknown command, or the wrong number of arguments prints one line that starts with ERROR and returns 2. Successful commands return 0.
