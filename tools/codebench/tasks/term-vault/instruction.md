vault.py in the current folder is an interactive program: it asks three questions on its standard input and, when all three answers are right, prints a line with an access code (code=...). The answers are in the files under data/. Run vault.py, answer its questions by looking at the files, and write the access code it prints (only the code, nothing else) into code.txt in the current folder. The code changes on every run of the benchmark, so it cannot be guessed. Do not change anything under data/.
