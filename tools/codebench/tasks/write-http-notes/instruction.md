faz um servidorzinho http em python pra guardar notas (so biblioteca padrao, um arquivo só, o nome vc escolhe). sobe com `python3 arquivo.py PORTA` e escuta em 127.0.0.1. rotas: POST /notes com json {"text": "..."} cria a nota e responde 201 com {"id": 1, "text": "..."} (o id começa em 1 e vai somando, e nao reaproveita id de nota apagada); GET /notes devolve a lista de notas em ordem de criaçao; GET /notes/ID devolve uma so; DELETE /notes/ID apaga e responde 204 sem corpo. tudo em json utf-8 com content-type application/json. id que nao existe (ou que nao é numero) da 404 com {"error": "..."}; json quebrado, sem o campo text, ou text vazio ou que nao é string da 400 com {"error": "..."}; rota que nao existe 404; metodo errado numa rota que existe (tipo PUT /notes) 405. as notas ficam so na memoria. tem que aguentar acento (ç, ã, emoji).
