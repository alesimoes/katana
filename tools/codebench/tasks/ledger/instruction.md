This project (package ledger/, with tests in tests/) reads a personal ledger and reports totals. Add currencies and monthly budgets, keeping the existing behaviour and the existing tests working. (1) Parser: after the amount a line may now have an optional currency code, exactly three uppercase letters, e.g. "2026-01-05 food -45.20 USD lunch with Bob"; Entry gets a new field `currency` (default "EUR" when the line has no code) and the note is the text after it. (2) New module ledger/rates.py: load_rates(path) reads lines such as "USD 0.92" (the value of one unit in EUR; blank lines and lines starting with # are ignored) and returns a dict that always contains "EUR": 1.0; convert(amount, currency, rates) returns the amount in EUR rounded to 2 decimals and raises KeyError for a currency that is not in rates. (3) Report: totals_by_category(entries, rates=None) converts every amount with convert() when rates is given; when rates is None every entry must be in EUR, otherwise it raises ValueError. New function monthly(entries, rates=None) returns a dict from "YYYY-MM" to a dict category -> total rounded to 2 decimals, with the same currency rule. New function over_budget(entries, budgets, rates=None) returns a list of tuples (month, category, spent, limit), sorted by month and then category, for each month and category whose spending is greater than budgets[category]; spending is the negative of the monthly total when that total is below zero, otherwise 0; categories that have no budget are ignored. format_report keeps working as before.
